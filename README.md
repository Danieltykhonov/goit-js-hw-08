# Домашнє завдання 8 — Галерея зображень

Галерея зображень з модальним вікном. Навчальний проєкт курсу GoIT Fullstack: робота з DOM, рендер розмітки з масиву даних і делегування подій.

## Що вміє

- Сітка з дев'яти зображень, по три в ряд.
- Зображення плавно збільшується при наведенні курсора.
- Клік по зображенню відкриває його велику версію в модальному вікні.
- Модальне вікно закривається кліком по затемненому фону.

## Як це зроблено

- **Рендер розмітки.** Елементи галереї створюються в JavaScript з масиву об'єктів `images`: `map()` перетворює кожен об'єкт на рядок з розміткою, `join('')` склеює їх в один рядок, і він записується в `ul.gallery` через `innerHTML` за одну операцію.
- **Делегування подій.** На весь список `ul.gallery` повішено один обробник кліка замість окремого на кожне зображення. Обробник через `event.target` перевіряє, що клікнули саме по елементу з класом `gallery-image`.
- **Скасування стандартної поведінки.** Кожне зображення огорнуте посиланням на велику версію, тому `event.preventDefault()` забороняє перехід за ним.
- **Велике зображення.** Посилання на нього зберігається в атрибуті `data-source` елемента `<img>` і читається через `getAttribute('data-source')`.
- **Модальне вікно.** Використано бібліотеку [basicLightbox](https://basiclightbox.electerious.com/), підключену через CDN. Колір фону модалки перевизначено у власних стилях.

## Технології

- HTML5
- CSS3 (Flexbox, transition, transform)
- JavaScript (ES6+)
- basicLightbox

```
├── css/

└── index.html
```

## Як запустити

1. Склонуй репозиторій або завантаж його архівом.
2. Відкрий `index.html` у браузері або запусти через розширення Live Server у VS Code.

Для роботи модального вікна потрібен інтернет, бо бібліотека завантажується з CDN.
